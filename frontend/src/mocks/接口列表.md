# Mock 接口列表

当前 Mock 系统共模拟了 **19 个接口**，分为以下几个类别：

## 📊 接口统计

- **登录相关**: 2 个接口
- **用户相关**: 10 个接口
- **项目相关**: 5 个接口
- **密码相关**: 2 个接口

---

## 🔐 登录相关 (2 个)

1. **POST /api/v1/login/access-token** - 用户登录
   - 测试账号：`admin@example.com`，密码任意
   - 返回：Token 对象

2. **POST /api/v1/login/test-token** - 测试 Token
   - 返回：当前用户信息

---

## 👥 用户相关 (10 个)

### 当前用户操作 (3 个)

3. **GET /api/v1/users/me** - 获取当前用户信息
   - 返回：当前登录用户信息

4. **PUT /api/v1/users/me** - 更新当前用户信息
   - 请求体：用户信息（full_name, email 等）
   - 返回：更新后的用户信息

5. **DELETE /api/v1/users/me** - 删除当前用户账户
   - 返回：成功消息

6. **PUT /api/v1/users/me/password** - 更新当前用户密码
   - 返回：成功消息

### 用户列表和详情 (4 个)

7. **GET /api/v1/users/** - 获取用户列表
   - 查询参数：skip, limit
   - 返回：用户列表（UsersPublic）

8. **GET /api/v1/users/:userId** - 获取单个用户
   - 路径参数：userId
   - 返回：用户信息

9. **POST /api/v1/users/** - 创建用户
   - 请求体：用户创建数据
   - 返回：创建的用户信息

10. **PUT /api/v1/users/:userId** - 更新用户
    - 路径参数：userId
    - 请求体：用户更新数据
    - 返回：更新后的用户信息

11. **DELETE /api/v1/users/:userId** - 删除用户
    - 路径参数：userId
    - 返回：成功消息

### 用户注册 (1 个)

12. **POST /api/v1/users/register** - 用户注册
    - 请求体：注册信息（email, password, full_name）
    - 返回：注册的用户信息

17. **DELETE /api/v1/items/:id** - 删除项目

## 💡 添加新接口

如需添加新的 Mock 接口，请在 `handlers.ts` 文件的 `mockHandlers` 对象中添加：

```typescript
'METHOD /api/v1/your-endpoint': async (config: AxiosRequestConfig) => {
  await delay(MOCK_DELAY)
  return createMockResponse({
    // 返回的数据
  })
}
```
