# Mock 使用说明

## 快速开始

### 1. 启用 Mock

在项目根目录的 `.env` 或 `.env.local` 文件中添加：

```env
VITE_MOCK=true
```

如果没有设置 `VITE_MOCK`，在开发环境（`npm run dev`）下会自动启用 Mock。

### 2. 运行项目

```bash
npm run dev
```

启用 Mock 后，浏览器控制台会显示：
```
🔧 Mock 已启用
所有 API 请求将返回 Mock 数据
```

## 功能特性

- ✅ 自动拦截所有 API 请求
- ✅ 使用 MockJS 生成随机数据
- ✅ 模拟网络延迟（300ms）
- ✅ 支持所有 CRUD 操作
- ✅ 类型安全（使用 TypeScript 类型）

## 支持的 API

### 用户相关
- `GET /api/v1/users/me` - 获取当前用户
- `GET /api/v1/users/` - 获取用户列表
- `GET /api/v1/users/:userId` - 获取单个用户
- `POST /api/v1/users/` - 创建用户
- `PUT /api/v1/users/:userId` - 更新用户
- `DELETE /api/v1/users/:userId` - 删除用户
- `POST /api/v1/users/register` - 注册用户
- `PUT /api/v1/users/me` - 更新当前用户
- `PUT /api/v1/users/me/password` - 更新密码
- `DELETE /api/v1/users/me` - 删除当前用户

### 项目相关
- `GET /api/v1/items/` - 获取项目列表
- `GET /api/v1/items/:id` - 获取单个项目
- `POST /api/v1/items/` - 创建项目
- `PUT /api/v1/items/:id` - 更新项目
- `DELETE /api/v1/items/:id` - 删除项目

### 登录相关
- `POST /api/v1/login/access-token` - 登录（用户名：admin@example.com，任意密码）
- `POST /api/v1/login/test-token` - 测试 Token

## 自定义 Mock 数据

### 修改数据生成

编辑 `src/mocks/data.ts` 文件：

```typescript
export const generateCurrentUser = (): UserPublic => {
  return Mock.mock({
    id: '@guid',
    email: 'your-email@example.com',  // 修改为你的邮箱
    full_name: '你的名字',
    is_active: true,
    is_superuser: true,
  })
}
```

### 添加新的 API Mock

在 `src/mocks/handlers.ts` 的 `mockHandlers` 对象中添加：

```typescript
'GET /api/v1/your-endpoint': async (config: AxiosRequestConfig) => {
  await delay(MOCK_DELAY)
  return createMockResponse({
    // 你的数据
  })
}
```

## MockJS 常用语法

- `@guid` - GUID
- `@email` - 邮箱
- `@cname` - 中文姓名
- `@ctitle(5, 10)` - 5-10 字标题
- `@cparagraph(1, 3)` - 1-3 段中文
- `@integer(1, 100)` - 1-100 整数
- `@date` - 日期

更多语法：http://mockjs.com/

## 禁用 Mock

设置环境变量：

```env
VITE_MOCK=false
```

或者删除 `VITE_MOCK` 环境变量，在生产环境下 Mock 会自动禁用。
